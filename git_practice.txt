(Command name )-git --version`                                   =>(Defination) Checks the installed version of Git on your system.                                              |
(Command name )-git config --global user.name "Your Name"`       =>(Defination) Sets your username, which will appear in all your commits.                                       |
(Command name )-git config --global user.email "your@email.com"` =>(Defination) Sets your email address, which will be associated with your commits.                             |
(Command name )-git config --list`                               =>(Defination) Displays all the current Git configuration settings.                                             |
(Command name )-git init`                                        =>(Defination) Creates a new Git repository in the current project directory.                                   |
(Command name )-git clone <repository-url>`                      =>(Defination) Downloads an existing remote repository to your local machine.                                   |
(Command name )-git status`                                      =>(Defination) Shows the current state of your repository, including modified, staged, and untracked files.     |
(Command name )-git add <file>`                                  =>(Defination) Stages a specific file so it is included in the next commit.                                     |
(Command name )-git add .`                                       =>(Defination) Stages all new and modified files in the current directory.                                      |
(Command name )-git commit -m "message"`                         =>(Defination) Saves the staged changes permanently with a descriptive commit message.                          |
(Command name )-git log`                                         =>(Defination) Displays the complete history of commits in the repository.                                      |
(Command name )-git log --oneline`                               =>(Defination) Displays a short, one-line summary of each commit.                                               |
(Command name )-git diff`                                        =>(Defination) Shows the differences between the working directory and the last committed version.              |
(Command name )-git branch`                                      =>(Defination) Lists all the local branches in the repository.                                                  |
(Command name )-git branch <branch-name>`                        =>(Defination) Creates a new branch without switching to it.                                                    |
(Command name )-git checkout <branch-name>`                      =>(Defination) Switches from the current branch to another existing branch.                                     |
(Command name )-git checkout -b <branch-name>`                   =>(Defination) Creates a new branch and immediately switches to it.                                             |
(Command name )-git switch <branch-name>`                        =>(Defination) Switches to an existing branch using the modern Git command.                                     |
(Command name )-git switch -c <branch-name>`                     =>(Defination) Creates a new branch and switches to it using the modern syntax.                                 |
(Command name )-git merge <branch-name>`                         =>(Defination) Combines the changes from the specified branch into the current branch.                          |
(Command name )-git branch -d <branch-name>`                     =>(Defination) Deletes a local branch that is no longer needed.                                                 |
(Command name )-git remote -v`                                   =>(Defination) Displays the remote repositories connected to your local repository.                             |
(Command name )-git remote add origin <repository-url>`          =>(Defination) Connects your local repository to a remote repository.                                           |
(Command name )-git pull`                                        =>(Defination) Downloads the latest changes from the remote repository and merges them into the current branch. |
(Command name )-git push`                                        =>(Defination) Uploads your committed changes from the local repository to the remote repository.               |
(Command name )-git push -u origin <branch-name>`                =>(Defination) Pushes a branch to the remote repository and sets it as the default upstream branch.             |
(Command name )-git restore <file>`                              =>(Defination) Discards all uncommitted changes made to a specific file.                                        |
(Command name )-git restore --staged <file>`                     =>(Defination) Removes a file from the staging area without deleting its changes.                               |
(Command name )-git stash`                                       =>(Defination) Temporarily saves uncommitted changes so you can work on something else.                         |
(Command name )-git stash pop`                                   =>(Defination) Restores the most recently saved stash and removes it from the stash list.                       |
(Command name )-git reset --soft HEAD~1`                         =>(Defination) Removes the last commit while keeping all changes staged for recommitting.                       |
(Command name )-git revert <commit-id>`                          =>(Defination) Creates a new commit that safely reverses the changes made by a previous commit.                 |
(Command name )-git show`                                        =>(Defination) Displays detailed information about a specific commit, including the changes it introduced.    =>(Defination)
